Open-source engineering plan · Rev {{ site.plan_rev }}

A self-sustaining Moon colony, built with technology we have now.

Open Moon is a public, step-by-step engineering plan for a permanent lunar base that grows into a colony. Every milestone is broken down into workstreams, components and sub-components. Each one names the real hardware it relies on, how ready that hardware is, what it costs, what can go wrong and how to fix it.

The rule: only technology that is flying, built or in active testing today, or credibly within 3–5 years. No warp drives, no space elevators, no fusion.
